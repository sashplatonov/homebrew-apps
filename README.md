# Sashplatonov Countpane

## How do I install these formulae?

`brew install sashplatonov/countpane/<formula>`

Or `brew tap sashplatonov/countpane` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "sashplatonov/countpane"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
